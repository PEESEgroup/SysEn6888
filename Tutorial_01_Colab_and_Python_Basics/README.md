Python types, collections, control flow, functions, and a synthetic energy summary.

**Runtime:** CPU; standard library only. Open the notebook, connect, and select **Runtime → Run all**. Dependency setup is included. Each notebook runs independently without local files or earlier lessons.

Start here if you are new to Python or notebooks. Expected results include a synthetic five-day total of 55 kWh and a mean of 11 kWh. Intentional exception examples are caught so they do not interrupt Run all. The final cell writes and reloads `outputs/tutorial_01/energy_summary.json`.
